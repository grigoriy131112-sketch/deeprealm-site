Файл создан и YAML валиден: `.github/workflows/dependabot-auto-merge.yml`.

Что он делает:
- Запускается на каждый `pull_request`, но работает только для PR от `dependabot[bot]`.
- Job **tests**: ставит Node/Python и прогоняет тесты (`npm test`, `pytest`), если в репозитории есть `package.json` / `requirements.txt` / `pyproject.toml`.
- Job **auto-merge**: запускается только после успешных тестов, получает метаданные Dependabot, одобряет PR и включает авто-merge (squash). Merge произойдёт автоматически, как только тесты (и другие обязательные проверки, если есть) пройдут.

Что нужно от тебя, чтобы я запушил это в GitHub:

# Deeprealm — сайт РП-чата

Сайт для тёмного фэнтези-РП чата Deeprealm: вся полезная информация о чате, ИИ-Проводник (чат-справочник) и ИИ-Анкетолог для проверки персонажей.

## Возможности

- **Главная** — краткое описание мира и как вступить.

## 2. Анкетолог для вступления в администрацию

Добавил новую вкладку «Администрация» с двумя частями:

**Справочная часть** — направления команды (зам владельца, пиарщик, модератор, разработчик, гейм-мастер, анкетолог, ивентолог), ступени роста (Практикант → Основная степень → Главный), общие правила команды и список вопросов, которые задают по каждому направлению. Всё взято со страницы администрации в твоём блоге.

**ИИ-анкетолог по кандидатам** — отдельный чат. Тут важная деталь: я не стал полагаться на то, что ИИ «сам догадается», что спрашивать. Модель упорно уходила в общий шаблон — спрашивала про Discord, Roll20, D&D, возраст, часовой пояс, гранты. Поэтому порядок вопросов я зафиксировал на сервере: для каждого направления есть свой список, и модель только перефразирует очередной вопрос, а не придумывает свои. Работает так:

- Модератора спрашивает, сколько готов активить в чате.
- Гейм-мастера — как часто готов писать посты и вести сессии.
- Пиарщика — как часто готов публиковать материалы и какие есть идеи для продвижения.
- И так далее по каждому направлению.

Если направление не названо, анкетолог сначала спрашивает, куда человек хочет. В конце, когда вопросы закончились, он даёт заключение с сильными сторонами, сомнениями и пометкой «РЕКОМЕНДОВАН», а решение остаётся за тобой.
