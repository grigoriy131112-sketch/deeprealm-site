Код для Cloudflare

Нажмите кнопку — код скопируется вместе с токеном бота. Останется вставить его в Cloudflare.

Что делать дальше
  1. Откройте dash.cloudflare.com → Compute (Workers) → deeprealm-relay.
  2. Нажмите «Редактировать код» (Edit code).
  3. Выделите всё и удалите.
  4. Вставьте скопированный код (долгое нажатие → «Вставить»).
  5. Нажмите «Развернуть» (Deploy).

Переменные после этого не нужны — всё уже внутри кода.
