# Информация кратко про сайт (для портфолио)

**Название:** «Логос» — блог для мыслей и публикаций
**Адрес:** https://grigoriy131112-sketch.github.io/logos/
**Тип:** блог / авторский сайт
**Статус:** готов, работает

**Задача:** место, где автор публикует тексты, а читатели находят их,
читают и обсуждают.

**Что умеет:**
- публикации с разметкой: заголовки, списки, ссылки, цитаты;
- лента с описанием, датой и временем чтения;
- поиск по тексту и заголовку, с учётом кириллицы;
- темы (теги) и облако тем;
- страницы авторов;
- тёмная и светлая темы с запоминанием выбора;
- реакции, прогресс чтения, «Случайная мысль»;
- комментарии через GitHub Discussions — отклики видит весь мир;
- RSS-лента, карта сайта, страница 404;
- «Мастерская»: личные записи читателя без регистрации — профиль хранится
  в браузере, есть выгрузка записей в файл.

**Стек:** Python 3, Flask, SQLite, Markdown, чистый CSS и JavaScript.
Без сборщиков и платных сервисов.

**Хостинг:** GitHub Pages — бесплатно, публикация автоматическая.
После правки контента сайт пересобирается сам, проверки прогоняются сами.

**Особенность:** GitHub Pages отдаёт только готовые файлы, сервера на нём
нет. Поэтому вместо обычных комментариев подключён Giscus — обсуждения
хранятся в GitHub Discussions, читателю достаточно войти через GitHub.

**Проверено:** тесты приложения, 30 проверок статики в браузере,
27 проверок «Мастерской», живая загрузка комментариев и смена темы.
