# Что есть на сайте — кратко

Сайт: https://grigoriy131112-sketch.github.io/deeprealm-site/

## Основной сайт

**Девять разделов:**

- Главная — кратко о мире, расах, классах, правилах и вступлении
- Лор — история по главам: создание мира, Единое Королевство, Великая Битва, Подземелье, раскол, Грохот
- Правила — семь разделов и система наказаний
- Расы — шесть базовых плюс расы, придуманные игроками
- Классы — пять базовых плюс свои классы
- Статьи — с поиском и фильтрами
- Пасс уровней — награда за каждый уровень
- Администрация — состав команды и роли
- Проводник — ИИ-справочник, отвечает на вопросы

**Три ИИ-помощника:**

- Проводник — консультация по лору, правилам, расам, классам, вступлению
- Анкетолог — ведёт диалог и собирает анкету персонажа, проверяет её
- Анкетолог по кандидатам — заявки в команду: зам, пиарщик, модератор, разработчик, гейм-мастер

**Расы:** Человек, Эльф, Драконорождённый, Дворф, Орк, Павший. Свои: Разумные цветы, Разумный слайм, Синтетики, Куклы.

**Классы:** Воин, Лучник, Маг, Некромант, Чернокнижник. Свои: Магистр сфер, Трикстер, Секироносец, Флагеллант.

**Мелочи:** переключение RU / EN, поиск и фильтры по статьям, адаптация под телефон, оформление под тёмное фэнтези.
