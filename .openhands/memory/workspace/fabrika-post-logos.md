# Статья для канала «ВебФабрика»

## Блог на бесплатном хостинге — и с комментариями. Как это устроено

Сделали блог «Логос»: место, где автор пишет тексты, а читатели их находят,
читают и обсуждают. Показываю, как он устроен и какую задачу пришлось решать
отдельно.

### Что умеет сайт

- публикации с разметкой — заголовки, списки, ссылки, цитаты;
- лента с описанием, датой и временем чтения;
- поиск по заголовку и тексту — с учётом кириллицы, без регистра;
- темы (теги) и облако тем: клик по теме — все тексты о ней;
- страницы авторов и подборка публикаций каждого;
- тёмная и светлая темы с запоминанием выбора;
- реакции на публикации, полоса прогресса чтения, «Случайная мысль»;
- RSS-лента и карта сайта — для поисковиков и читалок;
- «Мастерская»: личное место читателя. Регистрация не нужна — профиль
  хранится в браузере и никуда не отправляется. Можно писать свои тексты,
  править и удалять их, а кнопками «Сохранить копию» и «Загрузить копию»
  выгрузить записи в файл, чтобы они пережили очистку браузера.

### Главная сложность

Хостинг — GitHub Pages. Он бесплатный и надёжный, но отдаёт только готовые
файлы: сервера на нём нет. Значит, формы, которым нужен сервер, работать
не будут. Первым делом это ударило по комментариям — читатель писал отклик,
и его видел только он сам.

Вариантов было два: платить за хостинг с сервером либо подключить готовое
решение. Выбрали второе — Giscus. Это система комментариев, которая хранит
обсуждения в GitHub Discussions вашего же репозитория.

Как это работает для читателя: под каждой публикацией — окно откликов.
Чтобы написать, нужно войти через GitHub — одна кнопка, регистрация на
сайте не нужна. Отклики видит весь мир, а владелец модерирует их прямо
в GitHub. Обсуждение под каждой записью своё — они не смешиваются.
Стоимость — ноль.

### Что пришлось починить в процессе

Мелочь, которая видна всем: окно откликов не переключало тему. Ставишь
тёмную тему — а форма под ней остаётся светлой и слепит глаза.

Причина оказалась неочевидной: после загрузки Giscus удаляет свой тег
скрипта из страницы, поэтому менять настройки через него уже поздно.
Решение — передавать тему сообщением прямо внутрь окна. Проверили
переключение, а не поверили на слово.

### Что проверили перед сдачей

- тесты приложения — все сценарии;
- статика в настоящем браузере — 30 проверок;
- «Мастерская» — 27 проверок;
- живая загрузка окна откликов и смена темы;
- что окно откликов не показывает ошибку настройки.

Сайт публикуется автоматически: после правки контента достаточно отправить
изменения в репозиторий — проверки прогоняются сами, и сайт пересобирается.
